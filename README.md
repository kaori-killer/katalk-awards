# 🏆 카톡 시상식

카카오톡 "대화 내용 내보내기" 텍스트를 넣으면, 채팅방 사람들에게 상을 주는 시상식 페이지입니다.
정적 HTML 한 파일(`index.html`)로 되어 있고, 분석은 전부 브라우저 안에서만 이루어집니다. 대화 내용은 서버로 전송되지 않습니다.

## 상 목록
레전드 수다쟁이 · 답변 미니멀리스트 · 우리방 개그맨 · 나홀로 올빼미 · 너그러운 관객 깔깔이 · F감성 공감러 · 이구역 잼민이

## 로컬에서 보기
```bash
npx serve .
# 또는 그냥 index.html 더블클릭
```

## 배포 (Vercel)
1. 이 저장소를 GitHub에 올립니다.
2. https://vercel.com/new 에서 저장소를 Import 합니다.
3. Framework Preset: **Other**, Build Command/Output 비워 두고 Deploy.

공유 링크는 `#r=...` 해시에 결과만 압축해 담으므로 별도 백엔드가 필요 없습니다.
